# AppForges Python SDK

Official Python SDK generated by [sdk-gen](https://github.com/appforges/sdk-gen).

Python SDK M3 is under development. This repository does not yet contain a released Python package. TypeScript is available as `@appforges/sdk@0.59.2` on npm.

The Python distribution and import name will be `appforges`, with synchronous and asynchronous clients on Python 3.11+. Releases align exactly with the appforges-protos/openapi-spec tag.

Generated product source and its runtime will be committed directly to `main`; this repository does not contain the generator toolchain.
